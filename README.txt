САЙТ «МАМА, РАССКАЖИ» — МОБИЛЬНАЯ ВЕРСИЯ

Что внутри:
- index.html — главная страница, сначала платные персонализированные книги;
- skazki.html — бесплатная библиотека сказок;
- story.html — универсальная страница для сказок из Google Sheets;
- skazki/<slug>/index.html — отдельные красивые URL для 46 сказок из текущей таблицы;
- ebook-template.html — шаблон электронной персонализированной книги;
- assets/images — все изображения, которые можно менять без CSS;
- data/stories.js — текущая библиотека из Excel;
- data/config.js — подключение Google Sheets CMS;
- data/mama_rasskazhi_biblioteka_23_temy.xlsx — исходная таблица, которую вы прислали;
- IMAGE_GUIDE.txt — размеры и имена картинок;
- STORY_IMAGES.csv — список файлов изображений для каждой сказки.

КАК ЗАГРУЗИТЬ НА GITHUB PAGES БЕЗ КОМАНДНОЙ СТРОКИ
1. Распакуйте ZIP.
2. В GitHub откройте нужный репозиторий.
3. Add file → Upload files.
4. Загрузите ВСЁ содержимое этой папки, сохраняя папки assets, data и skazki.
5. Commit changes.
6. Settings → Pages → Deploy from a branch → main → / (root) → Save.

GOOGLE SHEETS КАК CMS
Сайт уже подготовлен для Google Sheets, но ссылка пока не заполнена, потому что был прислан Excel-файл, а не публичная Google-таблица.

Чтобы включить живое обновление без редактирования HTML:
1. Перенесите таблицу в Google Sheets.
2. Опубликуйте нужный лист как CSV.
3. Откройте data/config.js.
4. Вставьте публичную CSV-ссылку между кавычками в googleSheetCsvUrl.

После этого библиотека будет брать опубликованные строки из Google Sheets. Сайт понимает как текущие 10 колонок Excel, так и расширенные поля: URL изображения, URL аудио, Опубликовано, Дата публикации, Дополнительные темы и др.
Если Google Sheets временно недоступен, сайт автоматически использует локальную библиотеку из data/stories.js.
